# Product Edition

This distribution runs as a single, always-on product edition. All built-in capabilities are available
without a license key, registration, user cap, or device cap.

## Included capabilities

All model providers, authentication providers, MCP, skills, device enrollment, LLM proxy, and
hosted-agent features are available. Existing manifest `requiredEntitlements` fields remain accepted
for compatibility but do not restrict configuration or requests.
